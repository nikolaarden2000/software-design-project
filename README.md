# Веб-приложение для бронирования переговорных комнат

Веб-приложение для поиска и бронирования помещений для встреч, переговоров или отдаха. Пользователи может искать помещения по фильтрам, просматривать описание и бронировать онлайн.

Технологический стек:
  - Язык серверной части: Go
  - База данных: PostgreSQL
  - UI: Web (html/css + JavaScript)
  - Внешняя зависимость: API OpenStreetMap
